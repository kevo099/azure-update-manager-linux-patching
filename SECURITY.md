# Security policy

## Supported versions

Security fixes target the latest published release. Older tags are retained
for reproducibility but receive fixes only on a best-effort basis.

## Reporting a vulnerability

Please use this repository's private vulnerability-reporting or security
advisory flow. Do not open a public issue for a suspected vulnerability, and
do not include tenant IDs, subscription IDs, credentials, policy-assignment
exports, or other environment-specific secrets in a report.

For Azure platform vulnerabilities or service incidents, use Microsoft's
official security and support channels. This community project can address
defects in its policy definitions, scripts, examples, and documentation, but
it is not an Azure support channel.
